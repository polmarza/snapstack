# Página de detalle del repo con README (C-05)

**Fecha:** ver nombre del archivo
**Tipo:** Feature
**Requisitos:** C-05 (era MEJORA-03; nuevo en el PRD con esta feature)

## Qué se hizo

- Nueva ruta pública `/r/<owner>/<repo>`: la ficha en grande (misma data procedural que la
  tarjeta y la og:image), stats con clicks, autor con Follow, enlace a GitHub con señal
  `click_repo`, topics, JSON-LD (SoftwareSourceCode) y og:image propia. El título de las
  tarjetas del feed/perfil enlaza aquí. Repo inexistente o retirado → 404.
- **README cacheado en `repos.readme_md`** (migración 011, aplicada en local; **pendiente en
  producción**): se trae al importar con el token del usuario (REST `/readme`, que resuelve
  el nombre real del archivo) y con el nuevo `pnpm backfill:readmes [--remote]` (GITHUB_TOKEN
  opcional, como el seed). Tope 200k; si el filtro de moderación (S-01) salta, no se guarda.
- **Render seguro por construcción:** react-markdown + remark-gfm sin HTML crudo (los nodos
  HTML se eliminan del árbol, ni se interpretan ni se pintan como texto), enlaces/imágenes
  relativos reescritos a `github.com/...:blob` / `raw.githubusercontent.com`, esquemas que no
  sean http(s)/mailto anulados, `rel="nofollow"` en los enlaces del README.
- Backfill local ejecutado: 33/34 repos con README.
