# Reescritura del README para describir la plantilla

**Fecha:** 2026-05-14 12:30
**Tipo:** Documentación

## Qué se hizo

Reescrito por completo `README.md` para que describa la plantilla en sí (qué es, para quién, qué hay dentro, cómo funciona el protocolo y cómo empezar) en vez de ser un README placeholder para un proyecto hipotético.

Se mantiene una sección "Adaptar para tu proyecto" con la estructura sugerida que el usuario puede usar como guía cuando reemplace este README al adaptar la plantilla a un proyecto real.

## Qué se modificó

- `README.md` — reescrito completo

## Por qué

El estado anterior era un README placeholder con secciones tipo "Variables de entorno", "Instalación y desarrollo" rellenas de comentarios HTML pendientes. Útil para un proyecto que adopta la plantilla, pero confuso para alguien que llega al repo de la plantilla desde GitHub y quiere entender qué es y qué esperar de ella.
